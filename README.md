# EFX Media

A modern React + Vite application showcasing the portfolio, creative copywriting, and visual brand identity services of **EFX Media**.

## Features

- **Dynamic Typewriter Hero**: Interactive animated headline showcasing the agency motto and mission.
- **CEO & Creative Leadership**: Aaron's leadership message and vision for client growth.
- **Service Offerings**: Detailed breakdown of conversion-focused copywriting and visual design services.
- **Portfolio Showcase & Filter**: Filterable design archive (Logos, Social Media, Branding, Posters).
- **Interactive Fullscreen Lightbox**: High-resolution design previews with keyboard shortcuts (arrow keys, Esc) and detailed client info.
- **Extended Gallery View**: Comprehensive project showcase with automatic slideshow mode.
- **Why Choose EFX Media**: Value proposition cards and expandable detail accordions.
- **Client Testimonials**: Dynamic carousel of client reviews and star ratings.
- **Interactive Contact Form**: Client inquiry form with instant validation and status confirmation.
- **Dark Mode Support**: Persistent dark/light theme toggle preserving brand cyan/teal aesthetic.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Icons**: Lucide React
- **Typography**: Playwrite DK Uloopet & Plus Jakarta Sans
